# 開始處理前的專案確認頁

在「建立專案」填好來源、參考日期、環境、DEM／WBD 與處理設定，按「建立專案」會先顯示確認頁。此時還沒有建立專案或開始科學運算。需要修改就按「返回修改」，在原表單調整後重新預覽，不需要編輯 XML。

## 確認內容

- 實際解析的極化、對位參考日期、兩種後續日期數與電離層開關。空白項目由所選 ISCE2 決定；不以網站猜測預設值。
- 一般干涉與電離層網路各自顯示配對數、日期、連通群、未配對日期、逐組時間間隔。橫軸是日期，縱向只是日期排列，不是垂直基線。對位參考日期不等同之後 MintPy 的時間參考日期。
- 已選極化的正式 CEOS 影像描述、日期／frame 邊界、共同覆蓋與選用底圖。精度與限制同[影像辨識](IMAGE_IMPORT.md)。
- 自動以可取得的全部影像外框核對 DEM／WBD，而不是把 MintPy 裁切範圍當成 DEM 範圍。
- 來源／NAS 可讀性、空間、環境架構和恢復保護說明。容量是粗估，不顯示沒有根據的精確完成時間。

## 配對如何產生

在隔離的暫存目錄，使用選定環境的 `StackPulic.loadStackUserParameters` 和 `create_cmds.formPairs`。這會沿用該版對時間間隔、納入／排除日期及配對的處理順序。不是在瀏覽器重寫簡化版規則，也不執行 cmd1–4。若上游解析失敗，確認頁顯示錯誤，不能假裝預覽成功。

例如只有六個日期，後續日期數設為 9，沒有其他篩選時最多是 15 組，不是 54 組。兩種網路可有不同設定。未配對或分離群以警告顯示，允許研究者有意排除日期；零組一般配對、啟用估計卻沒有電離層配對、參考日期不在任何配對中會阻擋建立。

## 保存與核對

建立專案後 `.helper/confirmation.json` 保存設定、預覽、檢查時間、影像資訊、全部 Conda 套件版本，以及來源 LED／IMG 與地形的大小／修改時間。小型 XML／VRT、Conda 套件紀錄與配對程式另存 SHA-256。這不是大型影像的完整內容驗證，也不是完整環境鎖檔或二進位架構驗證。

確認後設定／輸入／環境紀錄變動會要求重做預覽；準備指令和開始運算前也核對輸入紀錄。cmd2／cmd3 產生後，實際配對與電離層解析結果會比對預覽，結果保存在 `.helper/confirmation-generated.json`；不一致即在科學運算前停止。既有指令雜湊檢查仍保留。

頁面「查看處理確認紀錄」顯示保存紀錄；歷史磁碟容量不是當下餘額，執行時會重新健檢。原有專案沒有建立時快照，頁面會明確說明，並使用原有的配對與設定；不重建假的歷史紀錄。雙日期目前仍沿用專用健檢，這份新確認頁只適用 alosStack。
