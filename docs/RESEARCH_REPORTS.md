# 比較成果與研究報告

完成 MintPy 分析後，專案頁的「比較成果，整理研究紀錄」提供兩個分頁。只有一個完成分析時可以產生報告；同一專案至少有兩個完成分析時可以比較。這些工具另存衍生成果，不重跑原始科學流程，也不覆寫 HDF5。

此入口目前適用於工作台完成的 alosStack，或經[手動成果匯入](LEGACY_IMPORT.md)建立的新專案。它不是任意 HDF5／所有 ISCE2 流程的通用報告器；匯入器目前只支援完整標準 alosStack 目錄。

## 比較兩個分析版本

1. 在「比較成果」選擇分析 A、B，按「建立成果比較」。例如比較不同時間相干性門檻或校正方法的兩次已完成分析。
2. 查看兩張地圖、有效比例、共同覆蓋、速度統計、參考點／日期與設定差異。地理預覽可同步縮放及移動；底圖預設離線，也可選擇線上底圖。
3. 點選有效位置，查看各分析實際使用的最終時間序列及其參考基準。相同原生格網可配對讀取同一像素；格網不同時不自動尋找鄰近像素替代。可下載點位 CSV。
4. 條件相容時才查看 B − A 差值；不相容時，畫面會列出原因並保留並排檢視。

直接相減必須核對完整原生經緯度格網、處理來源、空間／時間參考、單位、LOS 幾何、速度時間模型、實際擬合日期與時序日期，並有共同有效像素。相同影像尺寸或看起來重疊並不足夠；缺少舊紀錄也不以目前預設值補猜。差值只採共同有效像素，不把遮罩當成零。

地圖為抽樣預覽，完整統計與點位數值讀取原生資料。A、B 的統計各用自己的有效範圍，所以平均值不同也可能反映遮罩範圍不同。高相干性、較小不確定度或差值接近零，都不能單獨證明科學準確率。完整的條件、儲存與來源變更規則見[成果比較說明](COMPARISON.md)。

## 產生研究報告

1. 切換「研究報告」，選擇主要分析，填寫標題、作者與研究者說明。作者及說明可留空。
2. 如需兩版本比較，先在另一個分頁完成比較，再勾選「附上目前完成的兩版本比較」。主要分析必須是該比較中的 A 或 B。
3. 如需位移曲線，先在所選分析或比較地圖選取有效點位，再勾選「附上目前選取的原始點位曲線」。產生報告時會重新讀取所選分析的原始值，不擷取畫面數字作為資料。
4. 預設不包含完整本機資料路徑；只有重現需求確實需要時才勾選。按「產生可編輯研究報告」，完成後於報告紀錄下載。

| 下載項目 | 內容與用途 |
| --- | --- |
| 可編輯 Word `report.docx` | 可編輯文字與表格；圖表以獨立 PNG 嵌入，可移動、縮放或替換，圖中像素不是可編輯的數值圖層 |
| 可列印網頁 `report.html` | 自含圖片的 HTML，可離線開啟及使用瀏覽器列印／另存 PDF；不另外生成 PDF 檔 |
| 設定與來源 JSON `report.json` | 此次選定分析、設定、來源中繼資料指紋及附加比較／點位的快照 |
| 完整報告包 `research-report.zip` | 上述三種文件與報告使用的 PNG；不包含完整 SAR 影像或 HDF5 時間序列，不能取代研究資料備份 |

報告整理以下已記錄內容：

- 專案、流程、來源類型、作者、建立時間與工作台版本。
- 原始日期與配對、參考日期，以及可取得的電離層排除／處理歷史。外部匯入未提供的歷史保持「未記錄」。
- 每個選定分析的觀測日期、參考點／日期、有效像素、單位、軟體版本、校正執行紀錄與儲存的設定。
- 速度與時間相干性預覽；若選擇比較，加入兩個分析、比較條件、設定差異、共同覆蓋與可用的差值統計。
- 若選擇點位，加入按實際日期間隔繪製的位移曲線、日期／數值表與參考基準。

報告圖表不包含互動地圖的線上底圖。要說明地理背景，仍可在 Word 中另外插入有來源標註的地圖。研究問題、科學判讀及結論由作者撰寫；工具不自動挑選最佳參數。

## 來源、隱私與儲存

產生報告時會核對來源紀錄與科學檔案身分；來源中途改變、所選校正後時序遺失或比較已過期時停止，不把另一份結果補進同一報告。JSON 保存來源中繼資料 SHA-256；這**不等於全部大型 SAR／HDF5 內容的完整性驗證**。比較本身的快照與重新核對方式見[比較文件](COMPARISON.md)。

預設會將可識別的本機絕對路徑縮減為檔名。這不是完整匿名化：專案名稱、作者、研究者說明與檔名仍可能含有私人資訊，分享前請檢查文件。完整路徑未輸出時，別人重現分析仍需自行指定資料位置。

比較與報告位於工作台本機狀態目錄，預設根目錄為 `~/.local/share/alosstack-helper`，也可由啟動設定改變：

```text
<workbench home>/research/comparisons/<project id>/<comparison id>/
<workbench home>/research/reports/<project id>/<report id>/
```

這些紀錄不寫回原始科學專案。搬移專案資料夾不代表一併備份工作台狀態；需要保存或分享報告時，請下載完整報告包。外部匯入專案依然需要其來源磁碟；來源離線或變更時，應先恢復來源與核對狀態，再產生新報告。

## 科學與驗證邊界

單軌成果是相對參考點與參考日期的 LOS 位移／速度；正值朝向衛星，負值遠離衛星，不自動等於垂直下陷。非線性時間模型的一次項也不能一概稱為整段觀測期間的平均速度，應連同模型與擬合日期閱讀。

本機合成資料測試涵蓋圖表與文件產生、可編輯結構、原生點位、正確校正後時序、比較引用、來源唯讀、變更拒絕、取消、路徑縮減與輸出內容跳脫。這些是軟體行為驗證，不替代真實 SAR 影像的科學檢查。Sentinel-1 真實 IW SLC 端到端仍待驗證，topsStack 尚未開放；獨立評閱流程見[Sentinel-1 驗證紀錄](SENTINEL_VALIDATION.md)。
