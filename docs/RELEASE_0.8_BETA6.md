# SAR Workbench 0.8.0 beta 6

本版讓數值比較、操作位置與中斷處理更直觀，並把已知答案的科學軟體自測納入工作台。

## 介面

- ALOS 感測器相容性頁以逐日期數值圖與名目頻帶區間呈現差異，未知資料明確保留；共同頻帶估算仍不能代表可干涉或配準成功。
- 地圖、振幅比較、取樣差異與確認動作分段導覽；目前關卡可快速定位，重要限制保留，重複說明移入展開區。
- 專案總覽、工作流程卡片、側欄加入圖示與階段示意，改善窄螢幕配置。

## 自測與恢復

- 「工具與環境」新增進階自測，使用既有 ISCE2 / MintPy 環境執行五組小型案例，包含已知 2π 錯誤、DEM 誤差及異常日期。支援進度、取消、歷次紀錄與下載報告。詳見[進階自測](ADVANCED_SELFTEST.md)。
- 新執行的 MintPy 分析保存階段前副本；中斷後驗證來源、設定、環境與完整性，建立新的恢復版本。失敗的原版本保留，恢復後仍需確認人工關卡。詳見[中斷恢復](RECOVERY.md)。
- 非互動科學程序隔離標準輸入，避免 MintPy 將部分啟動方式的檔案描述符誤判為輸入檔。

## 相容性與驗證界線

不需重裝科學環境，未修改 Conda 套件。舊完成分析仍可瀏覽；沒有副本的舊失敗分析不能追溯恢復。階段副本增加儲存空間，尤其在不支援 APFS 複製的磁碟。

本機科學環境的 678 項測試全部通過；一般 Python 的 678 項測試通過，其中 186 項需科學套件而略過。另通過 9 組前端測試及原生自測的 27 項已知答案檢查。測試涵蓋原生 MintPy 合成流程、已知錯誤、地理匯出、取消、程序中斷與恢復，以及桌面／窄螢幕介面。精確測試結果與乾淨 Mac 安裝狀態以該 commit 的 [Actions](https://github.com/chris20011026/sar-workbench/actions/workflows/validation.yml) 為準。受控中斷測試不等於任意斷電與硬碟故障驗證；真實跨衛星人工影格確認不會因更新而通過。

原始碼和 Mac App 是不同下載項目；已發布安裝包與校驗值請見 [Releases](https://github.com/chris20011026/sar-workbench/releases)。
