# SAR Workbench 0.8.0 beta 4

這一版增加 ALOS 跨衛星中繼資料檢查及匹配後的人工品質關卡，並將日常操作與故障排查說明放進介面。已安裝的工作台在本機執行，不需要 ChatGPT／Codex 訂閱才能使用。

## 跨衛星相容性資料

在 alosStack 的影格與取樣檢查中，整理本次選定產品的波長、距離頻寬、Doppler 係數及來源欄位。候選影格只供比較，不會被加入本次處理。

共同頻帶顯示的是由產品中繼資料計算的**名義距離頻帶交集**，不代表實際頻譜、共同頻帶濾波或干涉品質已驗證。資料缺漏、未支援模式或無法完整涵蓋選定產品時保持未知。讀取器及統一取樣後的處理用 RSR／PRF 仍以取樣表為準。

## 匹配後先看品質，再開始干涉

啟用取樣統一的 alosStack 專案改為：

**讀取資料 → 影格人工確認 → 統一取樣 → 取樣成果確認 → 匹配與幾何 → 匹配品質確認 → 干涉處理。**

- 品質頁讀取實際 `ampcor.off`／`cull.off`，顯示保留點數、剔除比例、偏移分布及診斷殘差。
- 幾何偏移不當作相關匹配證據；剔除後退回原始點及缺少證據的情況會明確標示。
- 工作台的一階平面殘差是額外診斷，不是 ISCE2 的重取樣模型，也不是自動合格門檻。
- 使用者閱讀報告、填寫判讀依據並確認後，才開始 cmd2 及後續流程。報告、來源或匹配證據變更時，原確認失效。
- 重跑匹配階段的復原工作也會回到品質關卡。既有未啟用取樣統一的專案保留原流程。

詳細取樣、影格地圖、振幅預覽及驗證限制見 [ALOS 取樣流程](ALOS_SAMPLING.md)。

## 日常使用與維護

側邊欄的「使用與故障排查」提供可離線閱讀的操作說明。另附[日常操作、備份與故障排查](OPERATIONS.md)，包含外接磁碟重連、啟動／重開、失敗診斷、安全更新及解除安裝。先前只有主分支提供的影格地圖與並排振幅預覽也包含在此版程式中。

## 安裝與更新

Mac 安裝包名稱為 `SAR-Workbench-0.8.0-beta.4-macOS-arm64.zip`，需要 Apple Silicon 與 macOS 14.5 以上。下載及是否已發布以 [GitHub Releases](https://github.com/chris20011026/sar-workbench/releases) 為準；不要將 `Source code` ZIP 當作 Mac App。

先完成或停止背景工作，備份專案與工作台狀態，再關閉舊 App 並開啟新版。沿用原工具資料位置和狀態目錄即可保留登記；本版沒有要求替換既有科學環境，也沒有變更科學套件鎖定清單。

App 仍使用 ad-hoc 簽署，**尚未經 Apple Developer ID 簽署及公證**。請核對下載來源及附件 SHA256；不需關閉整台電腦的 Gatekeeper。ISCE3／NISAR 保持獨立實驗環境。

## 驗證界線

本版以既有完整測試、合成偏移／中繼資料案例、人工關卡及來源變更測試檢查行為；最終測試數與乾淨 Mac 安裝結果應以同一發布 commit 的 [GitHub Actions](https://github.com/chris20011026/sar-workbench/actions/workflows/validation.yml) 和 Release 紀錄為準。建置成功、App 簽章驗證與環境測試通過，各自只證明對應的軟體／安裝條件。

**未完成真實 ALOS-2／ALOS-4 混合影像從重取樣、匹配到干涉的完整科學驗證。** 現有真實五日期測試仍保留影格人工確認，不因更新程式便開始處理。Sentinel-1 IW SLC 與 NISAR RSLC 的完整真實資料驗證也仍有各自的限制；TOPS 多日期及通用 Stripmap 規劃項目沒有因此開放。

影格重疊、名義頻帶重疊或低診斷殘差都不能取代相干性、解纏、電離層、參考基準與獨立資料的判讀。單軌結果仍是相對 LOS 觀測，不自動等於垂直沉降。
