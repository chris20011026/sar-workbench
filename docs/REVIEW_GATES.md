# 校正、成果與 MintPy 判讀

這些檢查把運算結果交回研究者判讀，不以數值門檻代替科學結論。教學資料可以使用共同有效範圍練習，不必先指定正式研究區；跨衛星影格對應仍須人工確認。

## 1. 套用電離層校正後

alosStack 原本的電離層估計配對判讀仍然保留。確認排除清單後，工作台執行各日期電離層估計及校正，停在「等待檢查校正後結果」，不立即執行 cmd4。

- 比較校正前、估計的電離層相位與校正後的抽樣預覽；各圖的單位與顯示方式需一起閱讀。
- 在有效陸地查看大尺度異常、邊界、條紋與遮罩。平滑變化本身不是錯誤，校正後看起來較平滑也不能單獨證明校正正確。
- 填寫判讀依據並勾選確認，才開始解纏及地理編碼。
- 未啟用電離層校正時，不會出現虛構的「校正已通過」結果；仍需要 cmd4 成果驗收。

預覽採用降採樣，不是完整影像品質認證。資料缺漏會列出原因；不會用空白圖充當成功。按更新檢查只讀取產物並重建診斷，不重跑科學運算。

## 2. cmd4 成果驗收

cmd4 正常結束後，狀態為「等待成果驗收」。檢查分成三件事：

| 層次 | 代表什麼 |
|---|---|
| 程式成功退出 | 此次指令沒有回報失敗 |
| 成果結構檢查 | 各預期配對的產物、描述檔與影像結構符合要求；抽樣數值可讀 |
| 人工判讀 | 研究者已查看相干性、解纏與地理範圍等結果並留下依據 |

先處理表格中的缺漏與異常，再查看各配對預覽、確認成果。結構檢查通過不等於位移準確；解纏相位仍可能含大氣、軌道、地形與解纏誤差。完成本次人工確認後，才接續建立新的 MintPy 分析。

## 3. MintPy 解纏診斷

載入資料並確認空間參考點後，先產生診斷，再進行解纏錯誤修正及網路反演。

- **配對網路**使用載入後真正保留／移除的配對；原本表單中的預覽不等於原生門檻篩選後的最終網路。
- **連通區**是解纏區域標籤，顏色不代表相干性高低。跨區域的整週偏移需要結合相位及地理脈絡判讀。
- **相位閉合**統計三角形的非零整週閉合；沒有三角形或診斷未產生時顯示原因，不能讀成零錯誤。

確認診斷、留下理由後才進行反演與已選取的校正。若要改配對或方法，另建分析版本；不在已產生結果的版本中悄悄更改設定。

## 4. MintPy 殘差與日期

校正完成後，先查看 RMS 與逐日期資訊，再決定時間參考日期和速度模型的排除日期。

- RMS 需要實際的殘差時間序列。沒有殘差檔時會標示未執行與原因；不把空表當成「所有日期品質良好」。
- 高 RMS 日期只是需要檢查的候選。請結合空間分布、相干性、事件與校正方法決定是否排除；真實變形也可能呈現較大殘差。
- 建議排除日期須由使用者明確決定，並記錄理由。排除速度擬合日期不會刪除原始影像，也不同於移除干涉配對後重新反演。
- 時間參考日期與空間參考點是不同設定。重新選擇時間參考不能使不穩定的空間參考點變得可靠。
- 日期數或設計矩陣不足以估計所選時間模型時停止，不產生看似成功的速度結果。

確認後才執行時間參考與速度模型估計。原始 `proc` 不因這些分析改動；每次分析獨立保存設定、判讀與產物。單一視線 LOS 速度不能直接解讀成垂直沉降。

## 確認、刷新與舊版成果

確認綁定當時的診斷報告及來源證據，不能沿用另一份報告的同意。檔案變動或更新報告後，須重新查看與確認；切換專案與重新整理頁面不會自動按下繼續。

既有已完成專案仍可瀏覽及分析，不會自動重跑。舊版沒有的判讀紀錄會保留為未記錄，不補造同意或科學驗證。失敗時保存日誌與半成品，依既有恢復規則處理。

## 驗證邊界

自動化測試使用合成影像、HDF5 與隔離專案核對控制流程、統計、資料完整性、失效確認與介面。這不等於所有衛星與校正組合都完成真實資料驗證。正式研究仍需地理與物理合理性檢查，必要時與其他軌道或地面量測比對。
