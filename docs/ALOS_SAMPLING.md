# alosStack 讀取後統一取樣（Stripmap 試用）

新建 **ALOS-2 多日期** 專案時，在「處理設定 → 影格與取樣」勾選「讀取後統一取樣」。這個選項預設關閉；既有專案維持原流程，不會自動改寫已完成的成果。

ALOS-4 原始產品須先使用資料準備功能轉成受支援的 PALSAR-2 格式副本，再按 `YYMMDD` 整理 LED／所需極化的 IMG。本功能不會自動決定 ALOS-2 與 ALOS-4 的影格對應，也不把格式轉換視為科學驗證。

## 在網頁操作

1. 掃描來源資料。若部分日期有 0480、0490，但另一些只有 0480，可在影格清單選擇 0480；這只是讀取選擇，**不代表兩顆衛星的 0480 地理位置必然相同**。缺少指定影格的日期會被阻擋。
2. 勾選取樣統一、選參考日期，完成原有 DEM／WBD 與處理設定，建立並準備專案。
3. 按「讀取資料，前往影格與取樣檢查」。工作台只執行生成 cmd1 中的 `read_data.py`，接著顯示各日期／影格的 RSR、PRF、SLC 尺寸、虛擬來源與預計新增檔案量。
4. 人工核對各日期對參考日期的影格涵蓋、軌道及拼接安排。填寫確認依據並勾選確認；不知道時就保留在這個關卡。
5. 按「確認影格，統一取樣並繼續」。工作台先重取樣，再執行 cmd1 的剩餘步驟（包含基線與影像匹配），接續原有 cmd2、cmd3 人工電離層檢查及 cmd4 流程。

無須手動放置腳本或註解 `read_data.py`。原始 cmd1 保留供追溯；工作台只在自己的後續腳本排除讀取命令。未辨識的生成指令結構會停止，避免插在錯誤位置。

## 實際做什麼

- 參考日期保留原樣。每個比較日期的各影格／子波束，依參考對應單元的距離取樣率 RSR 與 PRF 重取樣；兩者差異均小於 1 Hz 時略過，沿用 ISCE2 的判斷門檻。
- 呼叫已選環境的 ISCE2 `contrib.alos2proc.resamp`，採用 `runPrepareSlc.py` 的線性座標縮放與尺寸計算。同時更新 swath 尺寸、取樣間距、PRF、Doppler 與方位 FM 多項式；三次式以 `p(ratio*x)` 直接轉換，避免建立大型座標陣列及再次擬合。
- `-virtual` 不需要事先生成實體 `.slc`。先驗證 `.xml`、`.vrt`、原始檔案長度、CFloat32 型別、位元序與 CEOS 列偏移，再由 ISCE2 直接讀取 VRT 指向的原始 IMG。需要重取樣的影像才生成新的實體 SLC。
- 對不在上游 nominal-rate 表中的合法 CEOS 距離取樣率，讀取程序以描述檔中的 MHz 換算。這個相容處理只存在於該次子程序，保留標準 ALOS-2 常數，不修改 Conda 套件或 shell 設定。

演算法依據：[ISCE2 runPrepareSlc.py](https://github.com/isce-framework/isce2/blob/main/components/isceobj/Alos2Proc/runPrepareSlc.py) 與 [alos2proc.py](https://github.com/isce-framework/isce2/blob/main/components/contrib/alos2proc/alos2proc.py)。上游的其他準備操作（例如共同頻帶濾波）不是本步驟的功能。

## 中斷與資料保存

新結果先寫到 `proc/helper_sampling/staged`，檢查尺寸、有限複數值與非全零內容後才替換 `dates` 中相應檔案。原始 SLC（如有）及描述檔移到 `proc/helper_sampling/before`，原始 CEOS 來源不修改。取樣相同的參考／其他影像不重寫。

多檔替換不是單一原子操作；使用 journal 與完成紀錄防止把中斷的半成品當成成功。失敗或拔除磁碟後會停止匹配，透過[恢復中心](RECOVERY.md)還原取樣前副本。請保留預設的復原保護；若自行關閉，未完成作業仍會保留備份並阻擋續跑，需要另行處理復原，不能按同一按鈕盲目重跑。

人工確認綁定當次讀取結果。小型描述檔使用 SHA-256，大型來源使用檔案長度與修改時間辨識（不是完整影像 checksum）。確認後若來源／描述檔改變，會阻止執行。成功結果再呼叫取樣步驟會先核對紀錄，不重複插值；後續階段的檢查點恢復也不重跑已完成的讀取與取樣。

## 驗證邊界

已用小型合成複數影像執行真正的 ISCE2 原生 resampler，檢查帶 CEOS 列填充的 MSB 虛擬來源、實體來源、升／降取樣、複數相位、係數轉換、原始檔案保留、不需取樣的略過、中斷發佈及過期確認。控制流程與瀏覽器測試另驗證人工關卡、不可自動選擇缺少的影格及續跑順序。

目前只開放支援的 Stripmap 模式，ScanSAR burst／Spotlight 不適用此接法。這不等於完成跨衛星精密對位或完整 ALOS-2／ALOS-4 真實干涉驗證；頻帶相容性、影格對應、相干性、相位及最終位移結果仍需研究者核對。
