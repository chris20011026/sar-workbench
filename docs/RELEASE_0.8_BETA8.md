# 0.8 beta 8：從零開始準備資料

新增工作台內的「從零開始」指引。從側邊導覽、專案總覽或建立專案畫面進入，依序理解工具、資料類型、資料夾安排、準備清單及下一步。

- ALOS-2 多日期提供詳細的原始產品、DEM／WBD、日期資料夾與處理成果說明。
- 依流程顯示不同需求，明確區分已開放、試驗中與尚未開放的入口；Sentinel-1 的 SLC／GRD 和 NISAR 的 RSLC／GUNW 不再混為一談。
- 區分使用者保存的原始產品與工作台建立的 imports、terrain、lessons、projects；說明符號連結、外接磁碟與運算路徑限制。
- 「我已確認」清單只供自行準備，不代表機器已掃描或科學品質已驗收；更換流程會清空勾選。
- 下一步按鈕只開啟現有畫面，不代按安裝、下載、執行或人工判讀確認。

完整文字版見[從零開始指引](GETTING_STARTED.md)，Mac App 下載與安裝見[第一次使用](FIRST_USE.md)。

## 驗證

本機控制流程套件執行 726 項測試，結果通過，其中 187 項需要選配科學環境或原生運算的測試略過；11 組 JavaScript 介面測試通過。另以實際瀏覽器檢查五步導覽、切換流程清空清單、未開放模式、資料匯入與教學入口，以及 390px 小螢幕。導覽測試未建立處理工作，既有真實專案仍停在原人工影格關卡。

發布附件須對應本版 commit 的乾淨 Mac 安裝驗證，詳情見該 Release 的驗證連結；以上控制流程測試不取代原生科學或真實影像驗證。

這次新增教學與導覽，沒有新增科學處理模式，也不代表未驗證流程已完成真實影像驗證。原始資料、現有環境與人工檢查關卡保持原有處理方式。
