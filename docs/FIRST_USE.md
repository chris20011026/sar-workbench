# 第一次使用 SAR 工作台

這份指南適用於 **0.6.0 beta 1 / Apple Silicon Mac，macOS 14.5 以上**。
不需要先安裝 Python、Conda、ISCE2 或使用終端機；首次安裝仍需要網路與下載時間。

## 1. 下載並開啟

1. 到 [下載頁](https://github.com/chris20011026/sar-workbench/releases/tag/v0.6.0-beta.1)，選擇 `SAR-Workbench-0.6.0-beta.1-macOS-arm64.zip`，不要選 Source code。
2. 解壓縮，把 `SAR Workbench.app` 放到你想保留的位置（例如「應用程式」），雙擊開啟。
3. 此測試版尚未完成 Apple Developer ID 簽署及公證。第一次可能需要依 macOS「隱私權與安全性」的提示確認開啟；請核對下載來源。不要關閉整台電腦的 Gatekeeper。
4. 按「準備並開啟工作台」。啟動器下載官方 Miniforge 並核對 SHA256，再開啟瀏覽器。之後雙擊 App 即可開啟網站，不需要 ChatGPT 或 Codex。

預設位置為 `~/sar-workbench`。若使用者名稱或路徑含中文／空白，在啟動器按「選擇位置」換成可寫入的英文路徑；這個選擇會被記住。專案的顯示名稱可以使用中文。

## 2. 讓工作台準備工具

在「開始使用／安裝工具」閱讀安裝內容，按「安裝並驗證運算工具」。工作台會安裝固定版本的 381 個套件，執行 15 項環境檢查，再跑小型 MintPy 相容性測試。全部完成後才顯示「可以使用」。

請保留至少 12 GB 工具／快取空間；衛星影像與處理成果另外計算，常會需要數十至數百 GB。下載速度依網路而異，進度與詳細紀錄可在頁面查看。安裝中斷可以重試：重用已下載的套件，建立新的環境，不覆蓋半成品。

此功能使用獨立的 Miniforge 和科學環境。原有 `insar`、`insar_arm`、shell 設定以及既有專案的環境路徑不會被替換。所有第三方工具保留自身授權；含 CS2 的部分元件限非商業用途，詳見 [第三方說明](../THIRD_PARTY_NOTICES.md)。

## 3. 先試小範例

按「先跑一個小範例」→「執行教學範例」。它會建立 8 個日期、18 組合成干涉圖，真正執行 MintPy 反演與速度估計。完成後點選格子，或輸入列／欄，查看位移曲線。

這份資料不對應真實地點，也沒有執行原始 SAR 影像的 ISCE2 處理。它用於理解流程及檢查安裝；誤差數字是和已知合成答案的差異。LOS 代表朝向／遠離衛星的位移，不能直接當作垂直沉降。

## 4. 準備自己的 ALOS-2 影像

1. 選「準備我的 ALOS-2 資料」，再選雙日期或多日期研究目的。
2. 用 Finder 選含產品的資料夾。可以有多個 ZIP、日期或 frame 的子資料夾；至少需兩個完整日期。MintPy 時間序列至少需三期，足夠觀測數仍取決於研究模型。
3. 按「檢查這批資料」。核對日期、frame、極化、Level 1.1 與缺檔提示。不同模式／重複產品須先分組，不由工具猜測。
4. 按「確認清單，整理到工作台」。ZIP 解壓到新的匯入資料夾；已解壓影像建立連結。同日期多個 frame 放在一起，兩份 `summary.txt` 都留在原處，不互相覆蓋。
5. 選既有 WGS84 橢球高 DEM 與 ISCE WBD，或展開「我還沒有 DEM／水體遮罩」取得公開地形資料。
6. 「帶入設定，確認專案」後，檢查參考日期、極化與處理設定，再建立專案。運算途中仍保留電離層與 MintPy 參考點等人工檢查點。

精靈目前支援 ALOS-2 Level 1.1。雙日期限同模式 Stripmap；Sentinel-1、通用 Stripmap 工作流尚未開放。檔名清單檢查不等於已驗證軌道、幾何或科學品質；後續 ISCE2 準備還會檢查。衛星資料的帳號、取得與授權仍由使用者處理。

## 地形資料的選擇

已有研究室的 DEM/WBD，可以直接選取，工具只檢查尺寸、座標描述與高程基準。請確定檔案覆蓋完整影像；NAS／原始檔案須保持連線。

免帳號下載選項使用 [Copernicus GLO-30 Public DSM](https://copernicus-dem-30m.s3.amazonaws.com/readme.html) 及相同產品 WBM。DSM 包含建物與植被，WBM 也不是 SRTM SWBD。高程透過 [PROJ 垂直格網轉換](https://proj.org/en/stable/operations/transformations/vgridshift.html) 由 EGM2008 轉為 WGS84 橢球高；來源 URL、SHA256、轉換方式與署名保存在輸出旁。

目前需輸入涵蓋**整幅 SAR 影像**的南北西東界線，支援南北緯 49° 內、最多 36 個一度圖幅。尚未自動推算原始影像外框。公開來源缺圖（包含部分純海洋圖幅）時會停止，不把缺圖猜成陸地或水體。這時請改用完整覆蓋的既有地形檔。

## 日常使用與中斷

- App 開著時，瀏覽器頁面可關閉／重開；「最近的準備工作」可找回匯入結果、地形與教學。關閉頁面不會停止背景運算。
- 科學處理時保持 App、電源與資料磁碟連線。避免闔蓋讓 Mac 休眠。
- 結束 App 前先完成或停止網頁中的工作。安裝工具可重試；正式 SAR 科學處理中斷後不自動接續半成品，需要先診斷。
- 已有環境的使用者按「我已有處理環境」，繼續使用原本完整表單，不必重新下載工具。

工具目錄內的 `runtime` 是正在使用的環境，不是可任意刪除的快取。`imports`、`terrain`、`lessons`、`projects` 分別保存整理資料、地形、教學及新手專案。請勿整個刪除 `sar-workbench` 資料夾。
