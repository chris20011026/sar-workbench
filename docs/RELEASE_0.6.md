# 0.6.0 beta 5 — 開始處理前的專案確認頁

ALOS-2 多日期建立前新增[專案確認頁](PROJECT_CONFIRMATION.md)：直接使用所選 ISCE2 解析 XML 和建立配對，分開顯示一般干涉與電離層網路、時間間隔、分離群及未配對日期；整合正式描述檔的影像地圖、DEM／WBD 覆蓋、磁碟與環境檢查。

建立後保存參數、輸入大小／修改時間、小型描述檔與配對程式雜湊、Conda 套件版本。產生 cmd2／cmd3 後再與預覽核對，不一致即停止。開始科學運算前再次顯示配對供確認。既有專案仍可查看原設定及已產生配對，沒有歷史快照的地方明確標示。

不是新的科學處理器，不提供精確工時或科學品質保證。雙日期仍使用既有專用健檢；其他衛星工作流不在本次更新範圍。

## 0.6.0 beta 4 — ALOS-2 影像資訊與覆蓋地圖

新增[影像辨識與匯入地圖](IMAGE_IMPORT.md)：沿用 ISCE2 讀取 CEOS 正式中繼資料，交叉核對檔名、日期、frame、極化和圈次；混合觀測提供候選組。可查看日期／frame 概略覆蓋、共同區域及選用 OpenStreetMap 底圖。ZIP 整理後補讀邊界；全部邊界可用時可帶入地形範圍與緩衝，並在精靈核對 DEM／WBD 覆蓋。

範圍是影像記錄的概略邊界，未做 DEM 地理定位，不代表相干性或有效形變成果。相對軌道與完整 ScanSAR 支援尚未完成。原始資料、既有處理成果與 Conda 環境保持不變。

## 0.6.0 beta 3 — ALOS-2 多日期恢復中心

新增[恢復中心](RECOVERY.md)：在主要階段前保存獨立的 proc 副本，失敗時顯示中斷位置、可能原因、保留內容與重跑起點。使用者確認後，完整核對副本雜湊、輸入紀錄、設定與套件紀錄，再保留半成品並還原重跑；不重複套用部分完成的電離層校正。人工判讀不跳過。

新專案預設開啟保護；舊專案需在運算前啟用，沒有副本不能補做安全續跑。保護增加磁碟讀取與儲存成本，APFS 優先使用獨立 clone，其他檔案系統完整複製。雙日期和 MintPy 恢復不在本版範圍。

測試涵蓋多階段失敗、校正重複保護、檔案變動／損壞、存活程序、搬移中斷及瀏覽器的確認流程；實際研究專案只做唯讀格式檢查，未執行回滾。

## Beta 2 — 資料健檢、環境共存與解除安裝

Beta 2 新增建立前的資料健檢摘要，以及既有專案的唯讀重新健檢。缺檔、日期／frame／極化不符、無效 CEOS 首筆紀錄、地形尺寸錯誤、不涵蓋使用者提供的外框、混合套件架構與最低空間不足會阻止開始。未知地形覆蓋與同軌完整性明確標示待確認。

處理、MintPy 和地圖使用隔離的子程序設定；選擇環境時同步選擇對應 Conda。Mac App 新增解除安裝工具按鈕，將專用 runtime 移至垃圾桶，保留影像與研究成果。啟動視窗不再自動啟動服務，方便先管理工具。

原生測試涵蓋環境／研究資料保留、可復原移動、運作中拒絕移除、未知路徑與符號連結保護。這不是對使用者正式安裝執行解除安裝；測試使用隔離資料夾。

## Beta 1 首次使用入口

此版把「先自行建立科學环境」改成 Apple Silicon Mac 上的圖形化安裝流程。

- 原生 Mac 啟動器：官方來源下載、SHA256 核對、私人 Miniforge、清楚的失敗／重試畫面。
- 固定 `insar-arm 0.2.0b1` 的 381 套件；15 項檢查與工作台自己的數值示範通過才啟用。
- 新手首頁、合成教學、日期／frame 清單、ZIP 匯入及 Finder 選擇器。
- 公開 Copernicus 地形／水體下載、高程基準轉換、ISCE 描述檔及來源紀錄。
- 最近準備工作的進度／成果恢復；保留原本進階表單、既有專案和原始資料。
- 包含 0.5 的 MintPy 常用／進階／全部參數介面，以及日誌請求失敗的局部錯誤處理。

支援範圍、資料準備與首次開啟方式見 [第一次使用](FIRST_USE.md)。此 Mac beta 尚未 Apple 公證；Linux 仍可從原始碼搭配既有環境啟動。Windows 原生、Intel Mac 自動安裝、另外四個 ISCE2 工作流及自動下載原始衛星資料不在此版範圍。

## 驗證方式

每次 main 更新與 pull request 都執行 [Workbench validation](https://github.com/chris20011026/sar-workbench/actions/workflows/validation.yml)：

1. 控制流程、輸入保護、JavaScript 語法與錯誤恢復測試。
2. 乾淨的 GitHub macOS ARM runner 編譯 App，以只有 macOS 工具的 PATH 執行原生 bootstrap。
3. 安裝完整固定科學環境，執行 15 項檢查和合成 MintPy 運算。
4. 使用發布包內的伺服器確認首頁、靜態資產、API 驗證、專用環境預選與重複服務保護，再執行科學格式／座標測試。

此工作流保留報告與下載包。只有成功的執行紀錄表示該次驗證通過；安裝、合成驗證與既有特定 ALOS-2 資料試跑都不代表所有衛星產品已完整驗證。

本機另有實際公開地形下載測試（臺灣小範圍，72 × 72 像素），獨立插值核對高程格網的符號與數值；以及瀏覽器的新手流程測試。私人路徑與研究資料不隨發布上傳。

## 從原始碼重建 App

需要 Apple Silicon Mac、Xcode Command Line Tools 與 Python 3.10+。一般使用者下載 App 不需要這些開發工具。

```sh
python3 tools/build_macos_app.py --output dist/macos-beta4
```

產生 `.app`、ZIP 與 `SHA256SUMS`。使用新的輸出資料夾，不覆蓋舊版；只打包程式、文件、前端函式庫和套件清單，沒有本機科學環境、帳密或衛星影像。
