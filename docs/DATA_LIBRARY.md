# 資料與成果瀏覽（第一階段）

側欄的「資料與成果瀏覽」可以選本機資料夾、NISAR `.h5`，或支援的設定檔。
使用 Finder 樣式選擇器，或在偏好設定切換網頁選擇器。中文路徑可直接讀取。
這個入口不建立處理專案、不執行來源腳本、不改寫環境或原始資料。

## 已提供

- ALOS-2／ALOS-4：按 LED 場景列出日期、Level、取樣率、IMG 數量與檔名極化。使用所選 ISCE2 環境的 CEOS schema。
- NISAR L-band RSLC／GUNW：從 HDF5 identification 讀取類型、日期、軌道、影格、頻段與極化，不只依檔名判定。
- RSLC 配對初查：比較日期、軌道、影格、升降軌與共同頻段／極化；不是完整配對或處理許可。
- `alos2App.xml`、`alosStack.xml`、`insar.yaml`：列出失效輸入路徑；stack 額外核對旁邊 data 資料夾中的參考日期；檢查 geocode 清單相鄰字串可能缺少逗號。
- 產品類型篩選、最近掃描紀錄。
- GUNW 地圖：頻段／極化下的解纏相位、纏繞相位、相干性、連通區、電離層相位屏與不確定度；僅顯示實際存在的圖層。
- 可選 OSM 底圖、透明度、完整範圍、相干性門檻、點選原始網格最近像素數值。

## 科學意義與限制

預覽先以固定步距抽樣（最長邊不超過 768 個樣本），再以最近鄰反投影到 Web Mercator（顯示最長邊不超過 900 像素）。不把雷達座標 PNG 直接拉伸到地圖。
點選讀取原始網格的最近像素，並使用同一套無效值／相干性篩選。
抽樣圖可能漏掉小區塊，不是分析或出版輸出。

- 原始相位顯示為 rad，不自動換算 LOS／垂直位移，不生成時間序列。
- 解纏相位會排除無效連通區；連通區是分類值，循環色盤超過 20 區會重複顏色，實際編號可點圖查詢。
- 相干性固定 0–1、纏繞相位固定 −π～π；其他連續值取有效抽樣的 2–98 百分位作色階。超出色階的值未被刪除。
- 兩種網格的相干性在選單中分開標示。門檻只套用同一網格的相干性；缺少相同尺寸圖層時會拒絕，而不自行猜測對應。
- 僅支援等距且北向上的 GUNW 投影網格；跨換日線或超過 Web Mercator 顯示緯度時拒絕預覽。
- ALOS 檢查尚不涵蓋 IMG 二進位完整性、共同覆蓋、頻寬、基線或跨衛星配準。ALOS-4 缺少已解讀欄位時明確標記，不以檔名猜測通過。
- ZIP 尚不在此入口展開；單次最多 20,000 個檔案、256 個候選產品／設定，配對初查最多列 100 組。大量資料應分批。
- NISAR ISCE3 運算、PALSAR-3 相容轉換、混合 ALOS-2／4 stack 尚未開放。既有 ISCE2／MintPy 入口不變。

## 環境與保存

網頁伺服器仍只依賴 Python 標準函式庫。讀取在使用者所選 Conda 環境的隔離子程序中執行，需 h5py、NumPy、pyproj、Pillow、matplotlib；ALOS LED 另需 ISCE2；YAML 檢查需 PyYAML。缺少套件時顯示錯誤，不自動安裝。

紀錄與預覽存放在工作台 state-dir 下的 `library/`，不複製 GB 級來源影像。讀取使用大小及奈秒修改時間檢查來源是否變動；這是變動偵測，不是內容校驗碼或完整性認證。
來源修改或搬移後請重新掃描。PNG 僅在成功完成後發布；API 沿用本機 Host／Origin／Token 保護。
OSM 底圖預設關閉，開啟後會連線取得當前範圍的圖磚；原始影像不會上傳。
