# 進階功能自測

在「工具與環境」選擇已安裝的 **ISCE2 / MintPy** 環境，按「執行進階自測」。不需要下載衛星影像或修改參數；它另外產生小型合成資料，執行原生 MintPy，並將結果和已知答案比較。執行中可停止；關閉分頁後可重新開啟查看結果。

這項自測補充既有的「環境基本驗證」與「小型教學範例」，不是重裝環境。

| 案例 | 檢查內容 |
| --- | --- |
| 已知位移 | 資料載入、參考點、分段診斷、反演、DEM/RMS 與最終速度 |
| 整週解纏錯誤 | 在指定區域注入 2π，確認閉合診斷能定位錯誤且不誤標其他區域 |
| DEM 誤差 | 注入已知高程誤差，檢查原生校正估計值與保留的位移訊號 |
| 異常日期 | 注入單日期偏差，檢查原生殘差 RMS 能辨識該日期 |
| 地理成果 | 人工經緯度網格、ROI、取點、GeoTIFF 與 PNG 匯出及來源不變 |

頁面顯示整體狀態、每項檢核、數值與日誌，可下載完整 JSON 報告。未完成的自測不算通過；先前個別項目的通過紀錄不會將取消或失敗的整體執行變成成功。報告記錄環境版本、時間、已知答案與驗證限制，位置在工作台狀態目錄的 `selftests/<代號>/`。保留歷次測試紀錄；測試不會更新 Conda 套件，也不登記或讀寫研究影像。工作台正在運算、安裝或搬移時不能同時開始自測。

## 能證明什麼

通過表示這組小型輸入在目前環境的受測路徑運作正常。合成網格不對應真實地點；測試不證明真實資料的對位、解纏或定位精度，也不涵蓋所有校正組合。大氣、潮汐、跨衛星及真實 Sentinel-1 全流程仍需各自的資料驗證。自動確認只出現在已知答案的測試副本，正式專案仍保留人工關卡。

## 開發與發布

一般測試會執行狀態保存、取消、互斥與中斷檢查。設定 `ALOSSTACK_ADVANCED_SELFTEST=1` 並在具備科學套件的環境執行 `tests/test_selftest.py`，會執行完整原生案例。`tools/check_release.py` 已啟用此測試，供乾淨 Mac 安裝驗證使用。
