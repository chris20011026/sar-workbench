# 專案儲存空間

適用於 0.7.0 beta 1。入口：**專案總覽 → 管理專案 → 儲存空間**，或專案內頁的「管理專案」。目前管理已登記的 ISCE2 專案，包含它的 MintPy 分析；NISAR 和格式轉換工作仍使用各自的紀錄。

## 使用方式

1. 按「開始統計」。預設只統計專案資料夾。
2. 若原始影像／DEM 在專案外，勾選「一起統計專案外的影像與地形資料」後重新統計。只使用此專案設定中明確列出的來源，不搜尋其他硬碟。
3. 查看讀取項目數與經過時間。因為尚未掃描的資料量未知，不顯示推測的完成百分比。
4. 可按「停止統計」。關閉視窗會讓統計繼續；關閉工作台則中止。已讀取的部分結果保留，但不標示為完整統計。
5. 接回磁碟或資料變動後按「重新統計」。離線時可讀取本機保存的結果與時間。重新統計失敗或停止時，保留上次完整統計；重新連結後會提示舊位置的統計可能不再適用。

## 分類

| 類別 | 範圍 |
| --- | --- |
| 原始／整理影像 | 專案內 `data` 及設定中指定的影像路徑 |
| ISCE2 處理成果 | `proc`，包含中間檔與最終成果 |
| MintPy 分析與匯出 | `analyses` 中非快取資料 |
| 恢復副本 | `.helper/recovery`，可能很大，但不能視為無用檔案 |
| 地圖與預覽快取 | `analyses/.map-cache`、各分析的 `cache`、`.helper/cache` |
| DEM／水體資料 | 專案內 `dem`、`wbd` 或設定中指定的地形路徑 |
| 工作紀錄與設定 | `.helper` 中非副本、非快取檔案 |
| 其他專案檔案 | 其餘實際位於專案內的檔案 |

外部來源另外列出，不加進專案內合計。相同或互相包含的來源只統計一次；來源包含專案資料夾時，會略過已計算的專案子樹。外部檔案可能被其他專案共用，這裡沒有推定擁有權。

## 數字的意義與限制

- **檔案容量**：一般檔案的邏輯大小，單位為 KiB／MiB／GiB。硬連結相同內容只計一次，歸入先讀到的類別；檔案數則保留項目數。
- **磁碟配置量**：系統回報的已配置區塊總量，放在統計細節中。APFS clone、壓縮與檔案系統共享區塊會影響解讀；它與邏輯容量均不等於刪除後能釋放的空間。
- **可用空間**：該磁碟在查詢時可供使用者寫入的空間，包含這個專案以外的使用情況，會隨時間改變。
- 不讀取影像內容，不做 checksum，不刪除、不搬移、不修改研究檔案。只在本機工作台狀態目錄 `storage-usage/` 保存紀錄。
- 不追蹤遍歷中遇到的符號連結。明確設定為輸入的連結可在勾選外部來源後，按其實際位置另外統計。樹內跨磁碟掛載點略過並列為不完整。
- 磁碟離線、權限不足或檔案在統計中消失會顯示不完整及問題位置，不把讀不到的資料當作零容量。問題清單最多顯示 20 項，但保留總數。
- 掃描不是檔案系統快照。運算仍在寫入時，結果可能跨越不同時間點；若需穩定數字，等運算完成後再統計。
- 同時只執行一個統計，使用低優先級的獨立背景程序。大量小檔案或 NAS 仍可能增加 I/O 負擔。極端系統 I/O 卡住時，停止訊號可能需等待作業系統處理，期間不啟動第二個掃描。

本版不提供「一鍵清理」，也不自動修改搬移後的科學路徑。安全搬移及可刪除產物判定需要另外驗證。
