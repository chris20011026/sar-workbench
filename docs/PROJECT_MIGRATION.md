# 已完成專案的安全搬移

在「專案總覽 → 管理專案 → 開啟安全搬移精靈」操作。這是先複製、驗證、再切換清單位置的流程，**原專案不會刪除，不會立即釋放原磁碟空間**。

1. 使用系統選擇器選擇存放位置，輸入一個尚未存在的新資料夾名稱。macOS 沿用 Finder 原生選擇視窗。
2. 預覽檔案總量、目的地可用容量、專案設定中的外部來源及符號連結。預留 64 MB 工作餘裕；稀疏檔與硬連結按獨立完整副本估算，不能用原磁碟的實際占用量推估需要的空間。
3. 確認後開始複製。檔案以獨立內容複製，逐檔比對 SHA-256，並再次核對完整清單。對於大型專案，完整讀取來源與副本需要時間。
4. 畫面顯示「驗證通過」時，專案仍登記在原位置。勾選確認並按「再次驗證並切換位置」，最後一次內容檢查通過後才會切換。

## 範圍

- 第一版接受由工作台建立、狀態為運算完成的 alosStack、alos2App、topsApp 專案，包含專案內既有的 MintPy 分析、匯出、日誌與恢復副本。軟體完成狀態不代表科學品質已經通過人工判讀。
- 原始影像、DEM 或 WBD 若位於專案外，保持原位置，**不會因為連結檔被複製就變成獨立資料**。預覽列出已設定來源與符號連結，不保證找出所有 XML、VRT、HDF5 外部連結、pickle 或指令內藏的路徑。
- 內部絕對符號連結改為指向副本內的位置；相對內部連結保留。相對外部連結轉成原位置的絕對連結。檔案內容保持原樣，不做全檔文字路徑替換。
- 不複製跨入另一個掛載磁碟的子目錄，不支援裝置檔、FIFO 等特殊檔案。目錄名稱大小寫衝突、權限限制或來源變更會停止，並保留現況。
- 這是內容與檔案清單的副本，不是完整磁碟備份；不承諾保留 ACL、擴充屬性、稀疏配置、硬連結關係、所有者或 Finder 標籤。新副本保留擁有者讀寫權限，讓使用者可以驗證和使用成果。

## 暫停、斷線與接續

可按「暫停搬移」。關閉瀏覽器視窗不會停止；結束工作台會暫停。重新開啟同一個工作台狀態目錄，再從專案管理回到搬移精靈。

接續時重新檢查來源身分、清單與已完成副本。中斷當下正在複製的單一檔案會重新複製；不是逐位元接續。磁碟須回到原選定路徑且身分相符。若掛載名稱改變、磁碟無穩定識別且裝置號改變、來源已修改，或目的資料夾遭替換，會保守停止；請恢復原位置，或結束這次紀錄並選擇另一個新資料夾重做。

「結束這次搬移紀錄」只結束本機紀錄，保留兩邊所有資料。未完成的副本有識別標記，不能當成驗證完成的專案匯入。工具不提供刪除原專案或自動清除未完成副本的動作。

搬移工作在獨立程序執行，停止有時間上限；若作業系統仍卡在磁碟讀取，會等舊程序結束才接受新的搬移。工作台結束時，子程序會停止。當搬移正在執行，會阻擋新的科學工作及會修改成果的操作；手動在其他程式修改來源則會在驗證時被偵測，請維持來源不變。

## 搬移後能做什麼

可查看專案紀錄、既有 PNG／GeoTIFF 匯出，以及工作台標準 MintPy 結果的地圖和時間序列。MintPy 會以副本中的分析資料夾解析原指定的時間序列檔；若校正後產品不見，不會偷偷換成未校正產品或回頭讀取原專案。

ISCE2 指令、XML、pickle、檢查點與 MintPy 運算設定仍可能包含原絕對路徑。**目前保留「搬移後不得直接續跑原科學流程」的關卡。** 要繼續原運算，需重新連結原位置或建立新的處理專案。外部連結成果仍需原始來源連線。

搬移本身不建立 Conda 環境、不更新 ISCE2／MintPy 套件，也不改變 shell 設定。版本與依賴來源紀錄隨專案保留。

## 驗證與紀錄

本機狀態目錄的 `migrations/<專案代號>/` 保存進度與 SQLite 檔案清單、檔案 SHA-256、來源及目的地身分。目的專案的 `.sar-transfer.json` 記錄複製是否驗證完成；不要自行移除或改寫以略過檢查。

自動測試包括內容一致與原檔保留、外部連結與循環、部分檔案中斷後接續、空間不足、內容被改動、來源增減、錯誤磁碟、目的地替換、服務中斷、子程序生命週期、API 權限及明確確認後才切換。合成 HDF5 測試會移除測試用原目錄，確認搬移後仍讀取同一個校正後時間序列，且數值一致。另以獨立測試工作台檢查桌面／窄螢幕操作。

上述測試不等於所有外接硬碟或 NAS 的實機斷電測試，也不新增真實 Sentinel-1／NISAR 科學品質驗證。

## 帶到其他位置繼續 MintPy

安全搬移保存整個既有專案及原始路徑，不會重新建立科學設定。如果目的是讓已完成的標準 alosStack 成果在另一台電腦建立新的品質檢查與 MintPy 分析，請使用[可攜分析資料包](PORTABLE_PROJECT.md)。它會完整收集後續分析必要影像並驗證，匯入時選擇當地環境、建立新專案代號。它不包含原始 SAR 全部資料、舊 ISCE2 檢查點或既有分析版本，不能取代整份研究備份。
