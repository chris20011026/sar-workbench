# SAR Workbench 0.8.0 beta 5

這一版補上電離層校正後確認、cmd4 成果驗收，以及 MintPy 的解纏與殘差人工判讀。各階段先保存報告，再等待使用者決定；不會將指令成功退出當作科學品質合格。

## 新的檢查流程

- **ALOS 電離層校正後**：並排檢視校正前後包裹相位及實際電離層差值，核對檔案與校正套用關係。填寫依據並確認後，才執行 cmd4。
- **cmd4 結束後**：逐配對核對地理編碼解纏、遮罩解纏、相干性與參考日期 LOS 幾何。產物缺漏不能直接驗收；確認後才標示完成並開放新的後續分析。
- **MintPy 解纏診斷**：查看實際採用的配對網路、閉合計數與連通區，再決定是否開始反演及已設定的校正。
- **MintPy 殘差判讀**：檢查 RMS 與逐期校正前後空間分布，明確選擇速度模型的排除日期及時間參考日期。RMS 建議不會自動套用；缺少殘差檔會標明未執行。

介面加入階段導覽、判讀提示、可展開的詳細證據及判讀紀錄。配對影像按需讀取，日期圖使用共同參考基準與色階。更新報告會撤回舊確認；過期報告、來源改變或不連通網路不能直接續跑。也修正慢速圖片回傳與切換專案時的介面競爭問題。

詳細操作與科學限制見 [校正、成果與 MintPy 判讀](REVIEW_GATES.md)。

## 更新與相容性

本版不要求重裝既有科學環境，沒有修改 Conda 套件或工具鎖定清單。MintPy 全零閉合圖的原生直方圖問題由工作台程序內的繪圖轉接處理，原生計算保留。舊版已完成的分析仍可瀏覽；不補造舊版本沒有的人工判讀紀錄。

先結束背景工作並備份專案與工作台狀態，再更新程式。Mac App 是否已提供及校驗值以 [Releases](https://github.com/chris20011026/sar-workbench/releases) 為準；原始碼 ZIP 與 Mac App 是不同下載項目。App 仍採 ad-hoc 簽署，尚未經 Apple Developer ID 公證。

## 驗證界線

本機已通過 641 項完整測試，包含實際執行 MintPy 的小型合成資料：兩次人工暫停、日期決策、RMS 檔案解析、速度數值及來源不變；一般 Python 環境的 641 項測試亦通過，其中 182 項需要科學套件而略過。另有瀏覽器實測與前端回歸測試。乾淨 Mac 安裝及發布版本驗證請對照同一 commit 的 [GitHub Actions](https://github.com/chris20011026/sar-workbench/actions/workflows/validation.yml)。

這些測試不等於真實跨衛星資料的完整科學驗證。真實 ALOS-2／ALOS-4 專案仍停在既有影格人工確認，不因本次更新而開始重取樣或匹配。Sentinel-1 與 NISAR 的真實全流程限制、尚未開放的 TOPS 多日期與通用 Stripmap 模式亦保持原狀。抽樣圖不是完整影像驗證；LOS 觀測不自動等於垂直沉降。
