# SAR Workbench 0.7.0 beta 2

此版將近期工作空間與專案管理功能納入 Apple Silicon Mac 下載包，並加入空間統計與已完成專案的安全搬移。

## 新增

- 安全搬移精靈：目的地與外部依賴預覽、可暫停的獨立複製、SHA-256 內容比對，以及確認後才切換登記位置。原專案保留。
- 搬移後 MintPy 讀取同一份分析內的原指定時間序列，避免偷偷讀取舊專案或改用未校正產品。

- 統一專案總覽、流程選擇、資料與成果、工具與環境入口。
- 專案顯示名稱、備註、加入既有專案，以及可復原的清單移除。
- 外接磁碟／已掛載 NAS 離線紀錄、原位置重連，以及以磁碟識別和專案代號核對的新位置連結。
- 「管理專案 → 儲存空間」：背景分類統計、外部來源去重、磁碟可用空間、停止與離線查看紀錄。
- NISAR／ALOS-4 實驗流程的介面與執行入口。ISCE3 仍需另外準備獨立環境；不會裝進 ISCE2 環境。
- 畫面側欄顯示版本，下載包與網頁功能更容易核對。

## 安裝與更新

下載 `SAR-Workbench-0.7.0-beta.2-macOS-arm64.zip`，解壓縮後開啟 App。需要 Apple Silicon 與 macOS 14.5 以上。首次使用會下載工作台專用工具，不需預先安裝 Conda。

已有 App 的使用者先完成或停止科學工作，結束舊 App，再以新版 App 取代。使用原工具位置，可沿用已驗證的工作台專用環境；這次沒有更新科學套件鎖定清單，不需要為新介面重裝整個環境。不同啟動方式須使用原狀態目錄，才會看到同一份專案登記。

此測試版採 ad-hoc 簽署，尚無 Apple Developer ID 簽署與公證。請由本專案 Release 下載並核對 SHA256；不要關閉整台電腦的 Gatekeeper。首次開啟的完整說明見 [第一次使用](FIRST_USE.md)。

## 驗證邊界

自動測試涵蓋空間分類、稀疏檔案、硬連結、符號連結、外部來源重疊、資料消失、停止、服務中斷、離線紀錄及 API 權限。介面另以獨立測試專案驗證桌面與窄螢幕。

GitHub Actions 使用乾淨的 ARM Mac 建置 App、啟動專用 Miniforge、安裝固定科學環境、執行環境檢查與合成 MintPy 驗證，再測試包內伺服器。Release 附件使用該次成功驗證的建置產物；記錄見 Release 所列的 Actions 連結。

這些是安裝、軟體與合成資料驗證。真實 Sentinel-1 TOPS、NISAR RSLC 端到端及混合 ALOS 科學品質仍未完成驗證。專案改變實際位置後，本版保留成果檢視，但仍禁止用舊絕對路徑直接續跑；搬移須由使用者選定目的地並確認，不自動清理研究資料。
