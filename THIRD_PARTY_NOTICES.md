# Third-party components

The bundled browser libraries retain their original licenses:

- Leaflet 1.9.4: BSD-2-Clause. See `src/alosstack_helper/static/leaflet.LICENSE`.
- Plotly basic 2.35.2: MIT. See `src/alosstack_helper/static/plotly.LICENSE`.

The Mac launcher downloads the pinned Miniforge distribution from conda-forge,
verifies its SHA256 before execution, and installs it into a private workbench
directory. Miniforge uses BSD-3-Clause; its installer and included packages retain
their own licenses: https://github.com/conda-forge/miniforge/blob/main/LICENSE

The optional science installer uses the exact `insar-arm 0.2.0b1` package lock,
redistributed here with attribution to https://github.com/chris20011026/insar-arm
(MIT-licensed installer/validation code). The synthetic lesson follows that
project's numerical validation fixture. Its synthetic arrays are generated by
this application; no private or licensed satellite data is bundled.

ISCE2, MintPy, GDAL, SNAPHU, ImageMagick and other science packages are downloaded
from their pinned package URLs. Their respective licenses apply, and are retained
inside their installed packages. The CS2-containing SNAPHU / ISCE2 components
have noncommercial-use restrictions; this distribution is not an unrestricted
commercial suite. Notices, upstream source archives, build recipes and checksums:
https://github.com/chris20011026/insar-arm/blob/main/THIRD_PARTY.md
https://github.com/chris20011026/insar-arm/releases/tag/v0.2.0-beta.1

The launcher beta has an ad-hoc local signature, not Apple Developer ID signing
or notarization. See the first-use guide for the macOS confirmation step.

The insar-arm MIT notice is retained in `src/alosstack_helper/resources/insar-arm.LICENSE`.

Optional terrain downloads use Copernicus GLO-30 Public DSM/WBM via its public AWS dataset and the NGA EGM2008 grid distributed by PROJ-data. Source URLs, hashes, transformation details and the required modified-data attribution are saved in each terrain output. These data are not bundled in the application. See the dataset's licensing and citation guidelines:
https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM
https://github.com/OSGeo/PROJ-data/blob/master/us_nga/us_nga_README.txt
